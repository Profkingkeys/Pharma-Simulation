# Contributing

Issues and pull requests are welcome for code quality, accessibility, game design, and pharmacist-reviewed curriculum work.

Before opening a pull request:

1. run `npm test`
2. run `npm run check`
3. keep real doses and unvalidated preparation instructions out of public missions
4. document the learning objective and failure condition for new gameplay
5. include tests for every state transition changed

Clinical or compounding claims require a traceable reference and professional review.
